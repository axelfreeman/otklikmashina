## 📊 Почему это работает

Ручной поиск работы — это математика. 1 приглашение на 50-70 откликов. Чтобы получить 2-3 собеседования в день, нужно отправлять 200 откликов. Человек физически не может столько. Бот — может.

| | Ручной поиск | ОткликМашина |
|---|:---:|:---:|
| Откликов в день | 10-15 | **200** |
| Приглашений в неделю | 1-2 | **14-21** |
| Время до оффера | 2-3 месяца | **1-2 недели** |
| Стоимость | 0₽ (ваше время) | **0₽ старт → 590₽/мес** |

## 🎯 Что умеет бот

- 🔍 **Автоматический поиск** — сканирует вакансии 24/7
- 📝 **Автоотклики** — отправляет резюме на подходящие позиции
- 🎯 **Умные фильтры** — город, зарплата, график, ключевые слова
- 📊 **Статистика** — сколько откликов → сколько приглашений
- 🆓 **Бесплатный старт** — первые 200 откликов без карты
- 🔒 **Легально** — бот использует ваше официальное резюме

## 🚀 Быстрый старт

1. Открой [@otklikauto_bot](https://t.me/otklikauto_bot) в Telegram
2. Подключи резюме с НН (SMS или токен)
3. Настрой фильтры: город, зарплата, график
4. Бот начинает откликаться — ты получаешь приглашения

- **Backend:** Python 3.11 + aiogram 3
- **API:** HH.ru OAuth, Telegram Bot API
- **Хостинг:** Docker + Ubuntu 24.04
- **Мониторинг:** Yandex Metrika + Ecommerce tracking
- **Сайт:** Astro 5 + Tailwind CSS, Nginx

## ❓ Часто спрашивают

### Это бесплатно?
Первые 200 откликов — бесплатно. Дальше — 590₽/мес за безлимит.

### Не заблокируют ли аккаунт на НН?
Бот использует официальное резюме. Это разрешённая активность — вы просто откликаетесь быстрее. 5000+ пользователей работают без блокировок.

### Сколько откликов нужно для результата?
50-70 откликов = 1 приглашение. 200 в день = 2-3 собеседования ежедневно.

### Какие данные нужны для подключения?
Только токен НН. Бот сам подключится к резюме и начнёт откликаться.
