## 🎯 Что делает

- Подключается к резюме на HH через API
- Автоматически откликается на подходящие вакансии 24/7
- Умные фильтры: город, зарплата, график, ключевые слова
- Статистика: сколько откликов → сколько приглашений
- Бесплатный старт: 200 откликов без карты
